# Publisher and Blog SEO Playbook

Use when the site publishes articles, news, guides, tutorials, reviews, or editorial content.

## Priority Checks
- Validate author bios, dates, update history, citations, editorial policy, and YMYL safeguards.
- Check topic clusters, article freshness, canonicalization, pagination, archives, tags, and thin index pages.
- Validate `Article`, `NewsArticle`, `BlogPosting`, `BreadcrumbList`, `ProfilePage`, and paywall markup when relevant.
- Check Discover/image readiness: strong images, descriptive alt text, visible bylines, and non-misleading titles.

## Common Opportunities
- Refresh decayed high-impression articles using GSC query evidence.
- Add concise answer blocks and Q&A sections for AI extraction.
- Build hub pages and contextual links across related articles.
