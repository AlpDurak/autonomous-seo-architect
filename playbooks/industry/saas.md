# SaaS SEO Playbook

Use when the site sells software, subscriptions, APIs, or B2B services.

## Priority Checks
- Map product, solution, integration, comparison, alternative, pricing, docs, and security pages.
- Check query intent split: problem-aware, solution-aware, product-aware, comparison, and implementation.
- Require strong trust assets: security page, privacy page, uptime/status, compliance claims with proof, customer logos only when present, case studies, integration docs, and clear pricing or contact path.
- Add or validate `SoftwareApplication`, `Product`, `Organization`, `FAQPage` where appropriate and visible.
- Build internal links between features, use cases, integrations, alternatives, and docs.

## Common Opportunities
- Competitor comparison pages with differentiated, non-defamatory claims.
- Integration pages targeting "[product] integration with [tool]".
- Bottom-of-funnel pages for "best", "alternative", "vs", "pricing", and "template" clusters.
- Developer documentation indexed only when it answers public implementation queries.
